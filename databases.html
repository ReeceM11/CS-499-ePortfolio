Travlr Getaway Application

This project is a full-stack travel application developed during CS 465 at Southern New Hampshire University. It uses MongoDB to store and manage travel information.

Enhancement Overview

For this enhancement, I focused on improving database reliability and data integrity. I updated the application to prevent duplicate trip codes and improve how trip records are created and updated. These changes help maintain accurate information and prevent database errors.

Files Modified

  • travlr.js - Improved the database model and validation.
  • trips.js - Improved trip creation and update operations.
