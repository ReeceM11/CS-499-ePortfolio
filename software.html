Software Design and Engineering

Travlr Getaway Application

This project is a full-stack travel application developed during CS 465 at Southern New Hampshire University. It includes a customer-facing website and an administrative interface for managing travel information.

Enhancement Overview

For this enhancement, I focused on improving application security, functionality, and error handling. I implemented role-based authorization to help prevent unauthorized users from modifying trip information. I also improved validation and error handling to make the application more reliable.

Files Modified

  • middleware/auth.js - Added authentication and authorization.
  • models/user.js - Added user roles.
  • controllers/authentication.js - Updated user registration.
  • controllers/trips.js - Improved validation and error handling.
  • routes/index.js - Protected administrative routes.
